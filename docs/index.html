Interview audio goes in. A speaker-separated transcript comes out. Nothing leaves the machine.

What it does

Trooper Transcribe converts recorded interviews and statements into timestamped text and separates the speakers, so a two-hour interview becomes a document you can read, search, and attach to a case file.

It runs from a USB drive on a standard Windows 10 or 11 workstation. Audio files, models, and transcripts stay on that machine. There is no account, no upload, and no network connection required once setup is complete.

Get it

The pre-configured version installs and runs without setting up Python or a build environment. The source version is free and requires you to assemble the environment yourself.

Speaker separation uses pyannote models. Each user accepts the model terms once on Hugging Face and downloads the weights during setup. After that, the tool operates offline.

For IT and command staff

Processing is local. Audio is never transmitted to a cloud service, an API, or a vendor server, and no case data is retained outside the folders you choose.

The tool does not generate content. It does not draft reports, summarize, draw conclusions, or produce investigative narrative, which places it outside the generative category addressed by KSP General Order AM-C-7a. Output is a mechanical transcription of recorded speech.

Transcripts are a working draft. The investigator is responsible for reviewing the transcript against the source audio before it is relied on or entered into a case file.
